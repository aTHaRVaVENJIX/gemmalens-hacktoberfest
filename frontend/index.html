            Why Unit Tests Fail To Catch Screen-Only Bugs
          

          

            Unit test runners (Jest, Vitest, Cypress component assertions) check DOM node existence and mock attributes, but do NOT compute rasterized GPU stacking contexts, subpixel font engine wrapping, or scrollbar metrics. Gemma 4 inspects the actual screen pixels to diagnose layout collisions.
          

        


        
        

          

            
              Case 01: Flexbox Child Collision & Truncation
            
            
              FLEXBOX
            
          

          

            The Bug: Default flex item min-width: auto prevents text from shrinking or truncating with an ellipsis, causing the title to overlap or shove sibling badges off-canvas.
          

          

            

              ❌ BUGGY (Screen Collision)
              .title { overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
            

            

              ✅ GEMMA 4 PATCH
              .title-wrap { min-width: 0; flex: 1 1 0%; }
            

          

        


        
        

          

            
              Case 02: Modal Z-Index Stacking Context Isolation
            
            
              STACKING CONTEXT
            
          

          

            The Bug: A modal with z-index: 9999 renders underneath a sidebar with z-index: 10 because an ancestor container has CSS transform, trapping the modal in a local stacking context.
          

          

            

              ❌ BUGGY (Stacking Trap)
              .card { transform: translate3d(0,0,0); }
            

            

              ✅ GEMMA 4 PATCH
              Portal to document.body or native <dialog>
            

          

        


        
        

          

            
              Case 03: Mobile Viewport 100vw Scrollbar Blowout
            
            
              VIEWPORT METRICS
            
          

          

            The Bug: 100vw includes the vertical scrollbar width, forcing the content width to exceed the mobile device screen and causing horizontal layout scroll on phones.
          

          

            

              ❌ BUGGY (100vw Overflow)
              .hero { width: 100vw; font-size: 42px; }
            

            

              ✅ GEMMA 4 PATCH
              .hero { width: 100%; font-size: clamp(1.5rem, 5vw, 2.5rem); }
